# Larkspur Retail · Client Portal v2

The customer portal for Larkspur Retail: orders and invoices, returns with a printable label,
vouchers and gift cards at checkout, saved addresses and the order emails.

Built by the Client Portal v2 team: Dan Cole (project manager), Lina Moreau (product owner),
Jordan Park (tech lead), Maya Haddad and Sam Rivera (developers), with Helpi Agent.

> A demo repository for [Octopora](https://octopora.com) and its series *Octopora in Action*.
> The people, the store and the history are fictional. Tickets are keyed `CP-<n>` in the
> Octopora project, and every branch, commit and pull request names its ticket.

## Run the tests

```sh
npm test
```

Node 24 or later (the tests run the TypeScript sources directly).
